# 外壳框架重构说明

2026-10-23 实施。原功能参照提交 `8bfd451`。原框架 13 个模块、61 个场景及智能方法名称保留，以内容回归检查验证，不冻结内部源码。

## 框架与职责

- Vue 3 和 TypeScript：应用入口、页面与生命周期。
- Vue Router：History 路由与查询参数；原 `#/...` 链接自动转换。
- 内容状态：`src/core/store.ts` 以版本号驱动的 computed 视图读取 `window.ATLAS / Cases`，运行时变更发出 `atlas:changed` 后刷新；不再使用 Pinia。
- 界面控件：`src/ui/` 自写弹窗、确认框、提示、分页、表格、方法多选与导入弹窗；不再使用 Naive UI。
- MiniSearch：全站检索与首页检索共用一个索引。
- Vite：模块发现、按需分包、开发及生产构建。
- fflate：用户主动下载模板时生成 ZIP，替换手写 ZIP 编码。

业务地图和专业图表仍使用项目自身布局与可视化；案例正文不作为 Vue 模板编译。案例算法与教师示例无需改用 Vue。

## 源码结构

```text
src/
  main.ts / App.vue / router.ts
  boot/runtime.ts         运行时加载顺序、全局事件与 data-* 委托
  boot/plugins.ts         plugins/ 自动发现、分类校验与延迟演示加载
  content/atlas.js        原始模块与场景内容（数据原样），索引与管理覆盖层
  runtime/                Cases 注册表、K 渲染工具、CaseDemoHost 演示宿主
  services/packages.js    CaseImport 与导入、存档、校验
  services/management.ts  管理账号与会话
  compat/admin.js         原 Admin.route/bind 兼容实现
  core/                   内容视图、检索、筛选、会话、动效
  ui/                     弹窗、提示、分页、表格、导入弹窗
  shell/                  顶栏、作业链目录、面包屑、页脚、全站检索
  components/ / pages/    公共组件与页面
plugins/<stage>/<scene>/<case>/
plugins/_templates/
deploy/nginx.conf
```

`content/`、`runtime/`、`services/packages.js`、`compat/` 保持经典脚本写法（IIFE 安装全局对象），构建检查脚本在 vm 中直接加载这些文件。

传统插件仍支持 `Cases.register`。目录分类使用实际 stageId/sceneId，构建验证唯一 ID 和目录匹配。演示异步加载具有切换取消、失败提示和重试。教师初至波示例保留为导入样例，不自动发布到内置案例库。

## 兼容边界

| 接口 | 保留行为 |
| --- | --- |
| 内容 | case.json 原字段；background/workflow/demo；Cases 注册、查询、注销；K 工具箱 |
| 演示 | page/module/builtin/auto；mount/unmount；原上下文对象；iframe 与 Shadow DOM；相对资源内联 |
| 导入 | CaseImport 原公开方法及同步返回类型；文件夹、多选、拖拽；模板；原校验；本地存储与导入优先级 |
| 管理 | Admin.loggedIn/route/bind；原 ATLAS 场景与方法 CRUD；案例编辑、隐藏、恢复；原账号与会话存档 |
| 导航 | 新 History 地址；旧 hash 地址及查询参数转换 |

新管理页与导入页由 Naive UI 实现，兼容层继续服务原调用。原存档键和结构保留，无强制迁移。渲染更新通过内容通知适配原同步 API。卸载演示时调用原清理钩子；框架不接管演示内部 DOM。

浏览器存储按来源隔离，切换端口或域名时需在原来源查看或重新导入。主站采用 HTTP 部署；独立案例仍能本地打开。History 部署必须设置页面回退，缺失静态资源返回 404，示例配置见 deploy。

## 验收入口

`npm test`：原标题、模块/导入/管理协议、旧存档、三类模块导出生命周期、案例算法与服务单元测试。

`npm run build`：标题和插件分类检查、TypeScript 检查、生产构建。

`npm run test:e2e`：Edge 真实操作，逐一检查全部61包的三个标签、桌面与手机布局、实际导入存档、独立离线、参数重算与CSV；另外保留教师包、管理、原链接和旧内置引用存档回归。原传统插件的注册行为由归档真实示例验证。

`npm run test:base`：独立子路径构建和浏览器深链接验收。

不自动创建或更新分发 ZIP。修改源案例后开发服务直接读取，生产构建直接使用源包。

## 全场景扩展

新增56个自包含教学包，与原5个钻井包一起覆盖61个场景。原welllog-layer脚本保存在测试夹具，站点同ID已替换为新清单式案例，已有builtin引用不用改包。恢复存档时延迟到挂载阶段解析内置引用，避免源插件尚未注册导致入口丢失，并检查循环引用。

首页显示实际全站覆盖量，可选择环节；案例库使用Naive UI分页，手机增加作业环节抽屉。默认内容状态同步为已收录。Vite按环节拆分案例正文和演示资源，文本资源不再同时以raw与URL重复输出；专业图表保持可读尺寸与局部滚动。

实际算法和资料列表见[全场景案例目录](全场景案例目录.md)，本轮验收范围见[全场景验收记录](全场景验收记录.md)。

## 外壳视觉还原（2026-10-27）

以 `8bfd451` 手写版的版式为基准重建外壳，模块、导入、管理接口不变。

- 样式：`assets/core/tokens.css` 为唯一令牌源，恢复色晕、网格和 14px 正文密度。外壳样式拆分为 `src/styles/{shell,home,pages,motion,naive}.css`；`assets/core/ui.css` 继续服务 `K.*` 输出的案例正文。原 `src/styles.css` 与未引用的 `assets/core/layout.css` 已移除。Naive UI 通过 `src/theme.ts` 对齐令牌。
- 布局：54px 毛玻璃顶栏与 1180 版心，窄屏用抽屉列出作业环节；页脚四栏含贡献与纠错邮箱。
- 首页：Hero 与速览面板双栏，下接作业环节链条、智能方法索引、方法与环节分布矩阵（热力分级，格子跳转 `/stage/:id?m=`）、系统分层结构。链条与矩阵悬停联动。
- 内页：作业链行式列表；环节页芯片筛选（写入 `?m/d/q/ready`）与上下环节翻页；方法页按环节分组；场景页恢复详情页头、无案例时的四段式与两栏相关场景；案例库为控制台式卡片。
- 组件：`components/layout`（顶栏、页脚、面包屑、页头、章节头）、`components/home`（速览、链条、方法面板、矩阵、分层）、`components/common`（场景行、方法标签、计数、比例条），数据访问统一经 `composables/useAtlas.ts`。
- 动效：路由切换、首屏级联、章节进入视口、数字计数、比例条生长、链条节点依次点亮、矩阵十字高亮、列表与标签面板过渡。`prefers-reduced-motion` 下全部关闭。
- 标题：原首页设问式章节标题改为“对象 + 属性”短语，解释移入副标题；模块与场景标题直接读取 `ATLAS`。

## 外壳重写

外壳与运行时实现整体重写，对外接口（`docs/contracts/shell-content-v1.json`）、存档键、路由与查询参数、`data-import / data-remove-case / data-restore-case / data-dl-template` 委托、演示上下文均不变。上一节的目录与组件说明以本节为准。

- 依赖：移除 Naive UI 与 Pinia。运行时变更（`Cases.register/unregister`、`ATLAS.reindex`）自行发出 `atlas:changed`，启动阶段不再包装公开函数。
- 运行时：`registry / kit / case-demo-host / packages / admin` 与 `atlas.js` 逻辑段改为现代 JS 并拆分小函数，K.* 输出的类名与结构保持原样；案例模板文本逐字保留。
- 视觉：暖色勘测纸底、墨蓝正文、钴蓝主色（`--jade`）、钻头橙强调（`--clay`），深色 Hero 带构造等值线纹理，深色页脚。令牌名不变，演示页继续继承。
- 首页：13 个环节改为自适应磁贴网格，方法索引为五张色条卡，矩阵五级热力，系统分层为三层条带。
- 内页：作业链为环节卡片（含场景子列表）；左侧作业链目录桌面为吸顶卡片，窄屏为底部弹出面板；筛选、场景卡片、标签页、案例库和管理页统一使用 `ui/` 控件。
- 测试：e2e 改用角色与可访问名称定位（如“场景目录”“方法与环节分布矩阵”“作业链目录”），d1 流程事实格从 case.json 读取期望值。
