# 全场景案例目录

本目录由 `node scripts/report_atlas.cjs` 从源包读取。主站保留原有13个模块和61个场景标题，每个场景对应一个内置教学包。原测井脚本已由新案例覆盖，旧脚本仅保存在测试夹具；教师初至波示例保留为导入兼容样例，不作为第二个内置案例。

全部演示为本地计算，数据、阈值、物性和响应系数按各包说明使用教学合成。这里列出实际轻量算法，不能将原场景设想中的深度网络或强化学习方向视为已实现。

## 验证入口

- `npm test`：原接口与存档、标题、全部源包覆盖、算法边界、独立指标复算及服务单元测试。
- `npm run build`：分类目录、标题、TypeScript及生产构建；不创建ZIP。
- `npm run test:e2e`：全部61包的三部分、桌面与窄屏、原入口实际导入、刷新恢复、独立离线、控件重算及CSV下载。
- `npm run test:base`：子路径History部署、深链接刷新、旧链接及资源404。

网页打开不等于现场有效；计算和浏览器验收的范围由对应测试脚本确定，专业资料与合成假设详见各包研究依据。
