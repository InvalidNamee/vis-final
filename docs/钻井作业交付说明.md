# 钻井智能化教学案例

学号末两位 29，对应第 3 类“钻井”。沿用原门户及“添加案例”契约，保留老师的 firstbreak 样例。

| 场景 | 源案例包 | 已实现方法 | 可核查结果 |
| --- | --- | --- | --- |
| d1 钻速预测与参数优化 | drilling-rop-case | 按井切分、多项式岭回归、约束网格搜索 | 推荐钻压/转速、测试 MAE/R²、均值基线 |

## 打开与导入

直接打开仓库根目录 `index.html`，进入“钻井”并选择场景。独立演示位于各包 `demo/index.html`，不需要启动服务器。

原门户“添加案例”接受文件夹或文件多选，不直接读取 ZIP。先解压 `.dist/drilling-*-case.zip`，再拖入整个案例文件夹。使用场景详情页的添加入口，会预填该场景的可用案例 ID。若从全站添加入口导入且同名内置 ID 已存在，请在原表单中改为唯一 ID（如 `drilling-warning-local`）；这是原导入器的重名校验规则。已有本地导入版本优先显示；修改源文件后，旧导入不会自动更新，应移除旧本地版本再导入，或使用内置版本。

## 同步构建与验证

在仓库根目录运行：

```text
python scripts/build_drilling_cases.py
node scripts/verify_drilling_rop.cjs
node scripts/verify_drilling_cases.cjs
```

保留原命令 `python scripts/build_drilling_rop.py`，用于仅构建第一个案例。案例文件夹为内容与算法源，内置 `assets/cases/drilling-*.case.js` 和 `.dist/*.zip` 均由构建脚本生成，不直接修改。`.dist` 被 Git 忽略，换电脑后重新构建。

各包内的 `ui.js` 与 `demo.css` 是本包自带资源，没有跨案例运行依赖。修改共享呈现方式时需同步四个新包；钻速案例保留原独立界面。
