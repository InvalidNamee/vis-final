# 射孔损害情景稳健搜索

## 业务对象

邻井经验不能消除近井损害厚度的不确定性，同一射孔方案在轻重损害情况下可能表现不同。设计时比较多个情景，可避免只对名义地层条件寻优。本例对每种孔密、相位、穿深在三种损害情景下评价，用最坏产量代理进行稳健排序。

## 第一手资料

- [SLB：射孔基本定义](https://glossary.slb.com/terms/p/perforate)：支持通过孔道连通储层、孔数尺寸方向影响产能，不支持教学参数优劣。
- [SLB：射孔策略](https://www.slb.com/-/media/files/oilfield-review/p54-69)：支持孔密相位穿深、损害带及表皮的定性联系，不支持教学代理系数或收益。
- [SLB：表皮](https://glossary.slb.com/terms/s/skin)：支持表皮为产能效率无量纲因子及正负含义，不支持表皮可唯一归因射孔。

资料查阅：2026-10-23。上述资料仅支持明示的定义与方法动机，不支持本例系数、阈值、型号、准确率或现场收益。

## 实际算法与数据

损害厚度乘0.7、1、1.3为人为不确定性情景，不是概率区间。产量代理含有效连通和表皮项，不能代表现场测试产能。

1. 按当前损害厚度×0.7/1/1.3构造三种假设。
2. 枚举100种孔密、相位及穿深。
3. 根据教学表皮公式预测产量，取三情景最小值。
4. 过滤预算及出砂代理上限，按最坏产量减成本惩罚选点。

默认输入（量纲见标签）：

- 渗流能力缩放编码：默认 50，范围 10–100，步长 5。
- 岩石强度编码 / MPa：默认 70，范围 30–120，步长 5。
- 损害带厚度 / m：默认 0.25，范围 0.05–0.6，步长 0.025。
- 教学成本上限：默认 65，范围 25–100，步长 5。
- 成本惩罚：默认 0.2，范围 0–1，步长 0.05。

## 指标与计算

最坏表现=min情景产量代理；目标=最坏表现−成本惩罚×成本。非概率稳健场景不能报告概率覆盖。

所有推荐与指标均来自 demo/model.js 的 run(inputs)，没有硬编码“提升比例”。绘图与CSV均读取同一次run结果。

## 教学假设与限制

没有实现真实弹型实验标定、储层模拟或井控设计。kh为教学缩放编码，产量单位仅便于解释响应；不输出装药或实际作业指令。

全部数据均为固定种子20261023的教学合成或显式教学案例表，未采集现场数据，不得宣传为实测收益。交互参数调节后的同一评价集只用于教学探索，不构成新的独立验证。原场景可能列出深度网络、知识图谱或强化学习方向，本例仅实现说明中的轻量方法。
