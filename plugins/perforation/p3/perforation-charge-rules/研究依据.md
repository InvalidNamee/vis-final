# 射孔弹型约束检索

## 业务对象

不同射孔弹设计在入口孔径、穿深和适用枪径上存在取舍，选型首先应检查井筒几何与适用环境。直接对所有型号评分会把不兼容候选排在前面。本例将规则过滤与偏好排序分开，逐型号列出温度、通径和壁厚的排除原因。

## 第一手资料

- [SLB：射孔枪系统](https://www.slb.com/products-and-services/innovating-in-oil-and-gas/completions/well-completions/perforating/perforating-gun-systems)：支持枪弹匹配与质量测试重要性，不支持任何虚构弹型性能表。
- [SLB：入口孔径](https://glossary.slb.com/Terms/e/entrance_hole.aspx)：支持入口孔径与穿深存在设计取舍，不支持虚构型号。

资料查阅：2026-10-23。上述资料仅支持明示的定义与方法动机，不支持本例系数、阈值、型号、准确率或现场收益。

## 实际算法与数据

结构化规则检索，不宣称构建了完整知识图谱或语义大模型。实际选型需厂家手册、API试验和井下应力校正；这里性能表是显式合成数据。

1. 提供六个明确标注教学名称的合成弹型编码。
2. 按井温编码、枪径和套管壁厚能力检查，保留排除原因。
3. 以强度编码对合成穿深作简单折减。
4. 对可行者按孔径/穿深偏好与成本排序，空集不返回推荐。

默认输入（量纲见标签）：

- 井温编码 / °C：默认 160，范围 100–220，步长 5。
- 最小通径 / mm：默认 80，范围 40–100，步长 1。
- 套管壁厚 / mm：默认 10，范围 6–18，步长 0.5。
- 岩石强度编码 / MPa：默认 60，范围 15–100，步长 5。
- 大孔偏好权重：默认 0.4，范围 0–1，步长 0.05。

## 指标与计算

通过数是规则检查结果；评分为归一化孔径与穿深加权减成本。没有现场正确型号标签，因此不展示虚假准确率。

所有推荐与指标均来自 demo/model.js 的 run(inputs)，没有硬编码“提升比例”。绘图与CSV均读取同一次run结果。

## 教学假设与限制

型号、温度能力、适用壁厚及性能全部虚构，不对应厂家产品。没有知识图谱推理或语义检索，不能用于射孔弹采购、装配或现场工艺选择。

全部数据均为固定种子20261023的教学合成或显式教学案例表，未采集现场数据，不得宣传为实测收益。交互参数调节后的同一评价集只用于教学探索，不构成新的独立验证。原场景可能列出深度网络、知识图谱或强化学习方向，本例仅实现说明中的轻量方法。
