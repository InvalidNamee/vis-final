# 孔道尺寸回归代理

## 业务对象

射孔孔道的有效穿深受靶件强度、围压与弹型性能影响，少量靶试需要与井下条件区分。代理模型可以快速比较编码组合，但不能把常压靶试直接当井下实效。本例以多批虚拟试验拟合穿深，按批留出评价，并显示能量响应与目标的交点。

## 第一手资料

- [SLB：射孔基本定义](https://glossary.slb.com/terms/p/perforate)：支持通过孔道连通储层、孔数尺寸方向影响产能，不支持教学参数优劣。
- [SLB：射孔枪系统](https://www.slb.com/products-and-services/innovating-in-oil-and-gas/completions/well-completions/perforating/perforating-gun-systems)：支持枪弹匹配与质量测试重要性，不支持任何虚构弹型性能表。
- [scikit-learn：岭回归](https://scikit-learn.org/stable/modules/linear_model.html#ridge-regression-and-classification)：支持带L2惩罚的最小二乘方法，不验证本例物理关系。
- [scikit-learn：数据泄漏](https://scikit-learn.org/stable/common_pitfalls.html)：支持仅以训练样本拟合模型和预处理、保留测试的原则。

资料查阅：2026-10-23。上述资料仅支持明示的定义与方法动机，不支持本例系数、阈值、型号、准确率或现场收益。

## 实际算法与数据

12个虚拟靶试批次，8批训练、4批留出。两个6项岭回归分别预测穿深与孔径，正则固定不使用测试选型。孔道轮廓按预测尺寸的平方根收尖形态示意，未模拟真实爆轰或三维CT。

1. 12批各20样本；8批拟合、4批测试。
2. 构造截距、能量、强度、围压、能量平方及能量×强度项。
3. 固定L2正则求解正规方程，未以测试集选择系数。
4. 比较测试MAE与训练均值基线，再枚举编码反求穿深目标。

默认输入（量纲见标签）：

- 教学能量编码：默认 80，范围 30–120，步长 2。
- 靶件强度编码 / MPa：默认 50，范围 15–100，步长 5。
- 围压编码 / MPa：默认 30，范围 5–65，步长 5。
- 教学穿深目标 / m：默认 0.6，范围 0.1–1.2，步长 0.05。

## 指标与计算

MAE=测试穿深绝对残差均值；均值基线只用训练穿深均值。推荐目标由同一回归模型计算，不使用生成真值直接推荐。

所有推荐与指标均来自 demo/model.js 的 run(inputs)，没有硬编码“提升比例”。绘图与CSV均读取同一次run结果。

## 教学假设与限制

实现穿深和入口孔径两个回归目标，收尖轮廓为几何示意；没有清洁度或三维形态预测。虚拟批次没有真实材料域差异，留批成绩不能外推真实靶试，能量编码不是装药参数。

全部数据均为固定种子20261023的教学合成或显式教学案例表，未采集现场数据，不得宣传为实测收益。交互参数调节后的同一评价集只用于教学探索，不构成新的独立验证。原场景可能列出深度网络、知识图谱或强化学习方向，本例仅实现说明中的轻量方法。
