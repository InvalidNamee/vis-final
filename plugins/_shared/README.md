# 案例可视化资源

`plugin-viz.js`、`plugin-viz.css` 和 `plugin-theme.css` 是 61 个独立案例使用的 SVG/Canvas 绘图源文件。每个案例的 `demo/` 内保存副本，保证本地打开和文件夹导入时不依赖其他案例目录。

- `demo/enrich.js` 将当前模型结果适配为图表描述，不改变已有预测、搜索和评价算法。
- UI 配色使用外部框架的 CSS 变量。`plugin-theme.css` 的低优先级默认层只供独立打开使用，同步时从 `assets/core/tokens.css` 读取；宿主主题及自定义主题可直接覆盖。原有图表、静态 SVG、图例及热力渐变中的旧色系也使用主题变量；栅格观测图的数据像素可保留。
- SVG 宽度最多 900px，且不超过绘图原始宽度；散点矩阵保持单元格等宽等高，按变量数排布在约 545px 高度内。图例与交互读数放在 SVG 滚动区外。图表默认锁定纵向滚动，仅在实际内容超过 600px 容器时开启纵向滚动；图像对照宽度最多 600px、高度最多 480px，保持原始比例。手机端在图表区域内横向滚动，不扩大页面宽度。
- 支持排序条形、哑铃、直方、箱线、矩阵、平行坐标、等值线、堆叠、流向、范围带、时间泳道、共轴剖面、方向玫瑰、散点矩阵及图像滑动对照。
- 公共库变更后执行 `node plugins/_shared/sync.cjs` 更新各包；执行 `node plugins/_shared/sync.cjs --check` 只检查副本一致性。两个命令均不创建 ZIP。
- 教师参考包 `seismic/s3/firstbreak-stalta` 不参与同步。
