# 示功图形态特征诊断

## 业务对象

示功图记录光杆载荷随位移的闭合轨迹，是有杆泵工况复核的重要入口。形状压缩成面积与上下半程载荷等特征后，可以用少量可解释模板先筛出异常。本例对三类理想化教学形态做最近质心分类，同时展示当前卡片和特征空间中的邻近关系。

## 第一手资料

- [SLB：示功图](https://glossary.slb.com/Terms/d/dynamometer_card.aspx)：支持载荷位移图用于泵工况诊断，不支持合成形态代表全部现场故障。
- [scikit-learn：数据泄漏](https://scikit-learn.org/stable/common_pitfalls.html)：支持仅以训练样本拟合模型和预处理、保留测试的原则。

资料查阅：2026-10-23。上述资料仅支持明示的定义与方法动机，不支持本例系数、阈值、型号、准确率或现场收益。

## 实际算法与数据

按18虚拟井切分12训练/6测试，各9张。以环面积、上下载荷均值做最近质心分类；没有使用CNN，当前探索卡由独立随机数后续生成。

1. 18虚拟井各9张卡，12井训练、6井测试。
2. 计算归一化闭合面积及上下载荷均值。
3. 仅按训练标签计算三类质心，欧氏距离分配类别。
4. 按未训练井计准确率与混淆矩阵，交互卡仅探索。

默认输入（量纲见标签）：

- 合成形态编码 0正常 1欠充满 2漏失：默认 1，范围 0–2，步长 1。
- 欠充满形态转折比例：默认 0.5，范围 0.2–0.9，步长 0.05。
- 载荷噪声 / kN：默认 4，范围 0–12，步长 0.5。
- 冲程 / m：默认 3，范围 1–5，步长 0.25。

## 指标与计算

准确率=测试井卡片分类正确数/测试总数；归一化面积除以冲程×35kN，不受冲程量纲直接放大。

所有推荐与指标均来自 demo/model.js 的 run(inputs)，没有硬编码“提升比例”。绘图与CSV均读取同一次run结果。

## 教学假设与限制

未实现CNN、杆柱波动方程或复合故障识别。虚构三类形态未覆盖气锁、断脱、结蜡等全部故障，真实诊断需作业结论校验。

全部数据均为固定种子20261023的教学合成或显式教学案例表，未采集现场数据，不得宣传为实测收益。交互参数调节后的同一评价集只用于教学探索，不构成新的独立验证。原场景可能列出深度网络、知识图谱或强化学习方向，本例仅实现说明中的轻量方法。
