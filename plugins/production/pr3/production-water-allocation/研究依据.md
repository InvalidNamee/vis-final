# 分层注水边际收益调配

## 业务对象

分层注水分配需要在有限水量与不同层段吸水能力之间权衡。已经高含水的优势通道继续增注，未必产生最大的增油响应。本例以三层边际递减的响应代理，在总量和层上限约束下分配小步水量，展示层间调整对整体目标的影响。

## 实际算法与数据

三层无交叉耦合的凹注采响应代理；等配可能违反层吸水上限，单独展示。未模拟真实连通系数、压裂压力、滞后与地层压力；不得作为配注指令。

1. 为三层定义吸水上限、含水编码和递减收益代理。
2. 总量以5m³/d离散，预算不足、容量用满或最大边际收益不为正则停止。
3. 每步选增配后目标增量最大的未满层，仅正收益时分配。
4. 输出各层配注、未分配量与等配目标，同时展示上限。

默认输入（量纲见标签）：

- 总配注预算 / m³/d：默认 300，范围 100–420，步长 5。
- 第一层吸水上限 / m³/d：默认 120，范围 40–180，步长 5。
- 第一层含水编码：默认 0.65，范围 0.1–0.9，步长 0.05。

## 指标与计算

目标=Σ[增益×(1−含水)×70×(1−exp(−q/70))−0.0005q²]；在总量不超过预算、同一分层凹函数和等步长下，正边际贪心分配是离散最优；允许保留水量。

所有推荐与指标均来自 demo/model.js 的 run(inputs)，没有硬编码“提升比例”。绘图与CSV均读取同一次run结果。

## 教学假设与限制

未模拟层间串流、注采滞后、压力或破裂；等配基线可能越过单层上限，不能当现场可行方案。所有收益是教学代理。

全部数据均为固定种子20261023的教学合成或显式教学案例表，未采集现场数据，不得宣传为实测收益。交互参数调节后的同一评价集只用于教学探索，不构成新的独立验证。原场景可能列出深度网络、知识图谱或强化学习方向，本例仅实现说明中的轻量方法。
