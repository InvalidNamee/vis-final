# 递减曲线时间留出预测

## 业务对象

产量递减预测可支持短期生产安排，但稳定工况趋势不能直接解释措施因果。本例比较指数与不同双曲递减形状，用早期历史拟合、较晚窗口选型、末期数据评价，展示时间外推误差和常数基线，避免随机打散时间造成乐观成绩。

## 第一手资料

- [SLB：生产优化](https://www.slb.com/solutions/production-optimization)：支持生产监控、人工举升和流动保障的应用背景，不支持本例递减参数及预测效果。
- [scikit-learn：数据泄漏](https://scikit-learn.org/stable/common_pitfalls.html)：支持仅以训练样本拟合模型和预处理、保留测试的原则。

资料查阅：2026-10-23。上述资料仅支持明示的定义与方法动机，不支持本例系数、阈值、型号、准确率或现场收益。

## 实际算法与数据

120天合成历史，0–59训练、60–79验证、80–119测试；测试不参与拟合或选型。当前控件反复探索后指标仅为教学对比，不是新独立现场评估。

1. 120天合成历史按60训练、20验证、40测试划分。
2. 枚举b=0/0.3/0.6/1及D网格，只在训练段求最优初始量。
3. 以验证MAE选择候选，测试不参与选择。
4. 报告末40天MAE和末7训练日常数基线，再预测未来。

默认输入（量纲见标签）：

- 初始合成油率 / m³/d：默认 90，范围 30–150，步长 5。
- 合成递减参数 / d：默认 0.012，范围 0.002–0.025，步长 0.001。
- 观测噪声幅值 / m³/d：默认 6，范围 0–16，步长 1。
- 未来预测 / 天：默认 30，范围 7–90，步长 1。

## 指标与计算

测试MAE与常数基线使用相同末期窗口；未来累计是逐天预测率求和。仅在同工况递减假设内成立，不给虚假置信区间。

所有推荐与指标均来自 demo/model.js 的 run(inputs)，没有硬编码“提升比例”。绘图与CSV均读取同一次run结果。

## 教学假设与限制

未使用时序神经网络、协变量或因果归因。未建模措施、停井、注采响应和非边界控制流，短历史与趋势突变会使外推失效。

全部数据均为固定种子20261023的教学合成或显式教学案例表，未采集现场数据，不得宣传为实测收益。交互参数调节后的同一评价集只用于教学探索，不构成新的独立验证。原场景可能列出深度网络、知识图谱或强化学习方向，本例仅实现说明中的轻量方法。
