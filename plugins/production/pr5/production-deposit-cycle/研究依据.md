# 沉积状态与清洗周期搜索

## 业务对象

蜡与无机盐沉积机制不同，但都会增加流动阻力并影响产量。固定清洗周期可能在慢沉积井过度作业、快沉积井处理不及时。本例明确把两种机制简化为状态累积代理，比较180天内不同清洗间隔的产量损失与作业成本，说明周期选择依赖沉积速率与经济假设。

## 第一手资料

- [SLB：结垢](https://glossary.slb.com/en/Terms/s/scale)：支持温压变化、混水不相容与盐类沉积导致堵塞，不支持本例含水线性沉积代理。
- [SLB：流体组分与析蜡温度](https://www.slb.com/products-and-services/innovating-in-oil-and-gas/reservoir-characterization/rock-and-fluid-analysis/fluid-analysis/composition-analysis)：支持析蜡温度、组分和沉积率需实验表征，不支持本例经验状态累积系数。

资料查阅：2026-10-23。上述资料仅支持明示的定义与方法动机，不支持本例系数、阈值、型号、准确率或现场收益。

## 实际算法与数据

结蜡温差累积+含水结垢代理；沉积状态非实验标定，清洗仅去除88%状态。温度低于析蜡温度促进教学沉积；无真实水化学饱和指数或生存模型。正向模拟所有周期取成本最小。

1. 温度低于析蜡编码产生温差项，含水引入独立教学结垢项。
2. 每日累积沉积，清洗日去除88%状态。
3. 损失率按1−exp(−状态)计算，加上实际模拟清洗次数成本。
4. 枚举7–60天间隔，选180天教学成本最小者。

默认输入（量纲见标签）：

- 析蜡温度编码 / °C：默认 45，范围 25–65，步长 1。
- 流动温度 / °C：默认 32，范围 15–65，步长 1。
- 含蜡编码 / %：默认 15，范围 2–30，步长 1。
- 含水结垢代理 / %：默认 50，范围 0–90，步长 5。
- 无沉积油率 / m³/d：默认 65，范围 20–120，步长 5。
- 教学油价 / 元每m³：默认 400，范围 100–800，步长 25。
- 单次清洗教学成本 / 元：默认 8000，范围 1000–30000，步长 1000。
- 当前清洗间隔 / 天：默认 30，范围 7–60，步长 1。

## 指标与计算

成本=Σ每日损失油率×教学油价+清洗次数×成本；推荐周期由同一模拟器穷举。未将沉积分数误称概率或真实结垢厚度。

所有推荐与指标均来自 demo/model.js 的 run(inputs)，没有硬编码“提升比例”。绘图与CSV均读取同一次run结果。

## 教学假设与限制

不含原油组分相平衡、水化学饱和度、流速剪切与化学兼容性；含水不是通用结垢概率。算法是状态模拟与计划优化，不宣称生存分析模型。

全部数据均为固定种子20261023的教学合成或显式教学案例表，未采集现场数据，不得宣传为实测收益。交互参数调节后的同一评价集只用于教学探索，不构成新的独立验证。原场景可能列出深度网络、知识图谱或强化学习方向，本例仅实现说明中的轻量方法。
