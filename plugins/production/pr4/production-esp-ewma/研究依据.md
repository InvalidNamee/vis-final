# 电泵电流温度渐变监测

## 业务对象

电潜泵退化可能在电流和温度曲线上缓慢显现，而运行频率改变也会产生相似信号。监测首先要建立可比的正常基线，再跟踪多通道偏移。本例使用仅由早期正常段计算的尺度和因果EWMA，展示报警延迟与误报权衡，报警进入人工复核。

## 第一手资料

- [SLB：电泵监控案例](https://www.slb.com/resource-library/case-study-with-navigation/al/lift-iq-north-sea-scale-squeeze-cs)：支持温度监测结合专家复核保护电泵的业务动机；现场案例阈值和收益没有移用到本例。
- [NIST：EWMA](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc324.htm)：支持指数加权递推与渐变监测动机；本例最大通道分数并非标准正态控制限。

资料查阅：2026-10-23。上述资料仅支持明示的定义与方法动机，不支持本例系数、阈值、型号、准确率或现场收益。

## 实际算法与数据

前60min仅校准，60–99正常监测、100–179渐变。EWMA只用当前及过去信息；阈值为最大标准化通道分数，不是故障概率或NIST正态控制限。合成异常起点不是失效时间。

1. 0–59min仅用于正常均值与标准差，不混入退化段。
2. 电流及温度分别换算成相对基线偏移。
3. 递推EWMA，取最大绝对分数并要求连续超限。
4. 在60–179min评价，正常40min计误报、退化80min计召回。

默认输入（量纲见标签）：

- 每分钟退化漂移 / A：默认 0.08，范围 0.01–0.18，步长 0.01。
- EWMA当前权重：默认 0.25，范围 0.05–0.8，步长 0.05。
- 教学异常分数阈值：默认 2.5，范围 1–5，步长 0.25。
- 持续超限 / min：默认 3，范围 1–8，步长 1。

## 指标与计算

检出延迟=退化窗首次持续报警时间−100；无报警显示不可定义。分数不是概率，召回按相关分钟样本计算而非独立故障事件。

所有推荐与指标均来自 demo/model.js 的 run(inputs)，没有硬编码“提升比例”。绘图与CSV均读取同一次run结果。

## 教学假设与限制

没有真实设备寿命标签，不能报告提前失效小时数。未区分气锁、结垢、电机绝缘与传感器漂移；正常工况切换需重新标定。

全部数据均为固定种子20261023的教学合成或显式教学案例表，未采集现场数据，不得宣传为实测收益。交互参数调节后的同一评价集只用于教学探索，不构成新的独立验证。原场景可能列出深度网络、知识图谱或强化学习方向，本例仅实现说明中的轻量方法。
