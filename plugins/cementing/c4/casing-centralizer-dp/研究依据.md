# 扶正器安放动态规划

## 业务对象

套管偏心会扩大宽边与窄边流速差，窄边泥浆残留使封隔更困难。扶正器数量有限时，等距安放未必覆盖高井斜或扩径段。本例在候选节点间计算跨距挠曲代理，用动态规划在固定预算下安排支点，并与同样数量的等距方案比较。

## 第一手资料

- [SLB：扶正器](https://glossary.slb.com/terms/c/centralizer)：支持偏心导致泥浆通道与封隔问题，不支持本例挠曲系数或安放方案。
- [SLB：固井](https://glossary.slb.com/en/terms/c/cementing)：支持固井前根据井径、密度和流变设计水泥浆体积与性能，不支持本例效率公式或压力窗数字。

资料查阅：2026-10-23。上述资料仅支持明示的定义与方法动机，不支持本例系数、阈值、型号、准确率或现场收益。

## 实际算法与数据

简化横向载荷挠曲代理，非API扶正器性能或真实套管梁模型；24个10m候选跨距节点，井径变化与井斜影响挠度。

1. 240m教学井段以10m节点离散，井斜与间隙随深度变化。
2. 支点间抛物线型挠曲结合载荷、井斜和间隙得到居中度。
3. 状态为已用跨距数和末支点位置，最小化居中不足平方损失。
4. 回溯推荐支点，与相同端点和数量的等距方案评价。

默认输入（量纲见标签）：

- 井斜基准 / °：默认 45，范围 0–80，步长 5。
- 环空间隙基准 / mm：默认 25，范围 15–45，步长 1。
- 横向载荷编码：默认 1，范围 0.3–2，步长 0.1。
- 跨距段数：默认 6，范围 3–10，步长 1。

## 指标与计算

最低居中度为全节点最小值；目标是Σ(100−居中度)²而非直接最大化最低值，因此两指标可能不同时改善。

所有推荐与指标均来自 demo/model.js 的 run(inputs)，没有硬编码“提升比例”。绘图与CSV均读取同一次run结果。

## 教学假设与限制

不包含真实扶正器回复力/起动力、摩阻及套管弯曲刚度，不能直接作为下套管布置表。端点固定、预算为跨距段数，实际扶正器数为预算+1。

全部数据均为固定种子20261023的教学合成或显式教学案例表，未采集现场数据，不得宣传为实测收益。交互参数调节后的同一评价集只用于教学探索，不构成新的独立验证。原场景可能列出深度网络、知识图谱或强化学习方向，本例仅实现说明中的轻量方法。
