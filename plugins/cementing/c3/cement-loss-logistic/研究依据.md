# 漏失风险逻辑回归

## 业务对象

施工前的漏失复核需要同时考虑压力窗口、流动压耗与裂缝发育。漏失记录通常不平衡，简单报告准确率容易掩盖漏判。本例训练带正则的逻辑回归，用可调阈值展示召回与误报的变化，并比较当前井况下各排量的风险分数。

## 第一手资料

- [SLB：固井](https://glossary.slb.com/en/terms/c/cementing)：支持固井前根据井径、密度和流变设计水泥浆体积与性能，不支持本例效率公式或压力窗数字。
- [scikit-learn：数据泄漏](https://scikit-learn.org/stable/common_pitfalls.html)：支持仅以训练样本拟合模型和预处理、保留测试的原则。

资料查阅：2026-10-23。上述资料仅支持明示的定义与方法动机，不支持本例系数、阈值、型号、准确率或现场收益。

## 实际算法与数据

36虚拟井次，前24训练、后12测试；逻辑回归全批梯度+L2。标签由带随机性的合成概率生成，风险阈值不参与拟合。小样本指标仅展示权衡。

1. 36虚拟井次整井划分24训练、12测试。
2. 训练集梯度下降拟合截距与三项特征；L2强度固定。
3. 按测试标签计算Brier、召回率与正常井误报率。
4. 枚举排量并保留低于当前阈值的候选，不修改模型。

默认输入（量纲见标签）：

- 压力窗宽 / g/cm³：默认 0.25，范围 0.07–0.57，步长 0.01。
- 排量 / m³/min：默认 2.5，范围 0.5–4，步长 0.1。
- 裂缝指示代理：默认 0.6，范围 0–1，步长 0.05。
- 教学分数阈值：默认 0.5，范围 0.1–0.9，步长 0.05。

## 指标与计算

Brier=平均(预测分数−0/1标签)²；召回率=TP/(TP+FN)，误报率=FP/(FP+TN)，分母为零显示不可定义。

所有推荐与指标均来自 demo/model.js 的 run(inputs)，没有硬编码“提升比例”。绘图与CSV均读取同一次run结果。

## 教学假设与限制

小样本合成概率未经现场校准，不是工程漏失概率；模型没有学习真实地层破裂力学。阈值探索不相当于获得新独立测试。

全部数据均为固定种子20261023的教学合成或显式教学案例表，未采集现场数据，不得宣传为实测收益。交互参数调节后的同一评价集只用于教学探索，不构成新的独立验证。原场景可能列出深度网络、知识图谱或强化学习方向，本例仅实现说明中的轻量方法。
