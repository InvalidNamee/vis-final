# 浆体密度与排量约束搜索

## 业务对象

注水泥时既要顶替泥浆形成连续水泥环，又要避免循环压力超过地层承受窗口。高排量可能改善顶替，却增加摩阻与ECD；密度增加又会改变静液柱。本例用明确的教学响应面同时画出这两种作用，在密度下界与ECD上界间比较候选，展示约束对推荐的决定作用。

## 第一手资料

- [SLB：固井](https://glossary.slb.com/en/terms/c/cementing)：支持固井前根据井径、密度和流变设计水泥浆体积与性能，不支持本例效率公式或压力窗数字。
- [SLB：扶正器](https://glossary.slb.com/terms/c/centralizer)：支持偏心导致泥浆通道与封隔问题，不支持本例挠曲系数或安放方案。

资料查阅：2026-10-23。上述资料仅支持明示的定义与方法动机，不支持本例系数、阈值、型号、准确率或现场收益。

## 实际算法与数据

教学经验响应面，不是标定水力学或实际顶替效率。ECD采用简化排量平方摩阻项；破裂当量密度与孔隙压力由用户指定。

1. 指定环空间隙、居中度及两条当量密度边界。
2. 枚举25种浆体密度和36种排量，不外推范围。
3. 分别计算密度加平方摩阻项与饱和顶替响应。
4. 过滤越界候选，再最大化顶替代理减排量惩罚。

默认输入（量纲见标签）：

- 当前浆体密度 / g/cm³：默认 1.7，范围 1.35–1.95，步长 0.025。
- 当前排量 / m³/min：默认 2，范围 0.5–4，步长 0.1。
- 孔隙当量密度 / g/cm³：默认 1.35，范围 1.2–1.7，步长 0.025。
- 破裂当量密度 / g/cm³：默认 1.85，范围 1.4–2.2，步长 0.025。
- 环空间隙 / mm：默认 25，范围 15–45，步长 1。
- 居中度 / %：默认 75，范围 30–100，步长 5。

## 指标与计算

可行组合数直接计数；推荐目标=顶替代理−0.015Q²。展示当前与推荐ECD，不预填真实顶替提升。

所有推荐与指标均来自 demo/model.js 的 run(inputs)，没有硬编码“提升比例”。绘图与CSV均读取同一次run结果。

## 教学假设与限制

未计算真实非牛顿流变、温压密度、浆柱分段、窄边窜流或漏失起裂；0.03密度裕度完全是教学设定。无解时保留无可行结果。

全部数据均为固定种子20261023的教学合成或显式教学案例表，未采集现场数据，不得宣传为实测收益。交互参数调节后的同一评价集只用于教学探索，不构成新的独立验证。原场景可能列出深度网络、知识图谱或强化学习方向，本例仅实现说明中的轻量方法。
