# 完井相似案例排序

## 业务对象

裸眼、套管射孔、筛管和砾石充填对储层接触、防砂与投入有不同取舍。邻井案例能提供经验线索，但相似地质与工况比单纯高产排名更有意义。本例在合成案例库中检索相近储层，再按防砂偏好给方式排序，公开距离、支持案例数和评分组成。

## 第一手资料

- [SLB：完井系统](https://www.slb.com/products-and-services/innovating-in-oil-and-gas/completions)：支持裸眼、套管、防砂及智能完井的业务组成，不支持虚拟邻井评分。

资料查阅：2026-10-23。上述资料仅支持明示的定义与方法动机，不支持本例系数、阈值、型号、准确率或现场收益。

## 实际算法与数据

64个虚拟案例。距离按预设物理尺度归一化，16近邻按倒距离加权；缺少某类时按相同三维距离回退该类最近2例，明细列出支持井号和回退标记。不训练神经网络，评分没有真实经济含义。

1. 用预设尺度比较渗透率、出砂倾向与出水编码。
2. 64案例中取16近邻，避免井号进入距离。
3. 每种方式以倒距离权重汇总产能、出砂与成本代理。
4. 显式评分权重排序，展示稀疏类别回退支持量。

默认输入（量纲见标签）：

- 渗透率 / mD：默认 240，范围 20–820，步长 20。
- 出砂倾向编码：默认 0.6，范围 0–1，步长 0.05。
- 出水风险编码：默认 0.3，范围 0–1，步长 0.05。
- 出砂惩罚权重：默认 1.5，范围 0–3，步长 0.1。

## 指标与计算

案例距离为三维归一化欧氏距离；评分=产能代理−出砂权重×出砂代理−0.006×成本。未定义准确率，不伪造推荐命中率。

所有推荐与指标均来自 demo/model.js 的 run(inputs)，没有硬编码“提升比例”。绘图与CSV均读取同一次run结果。

## 教学假设与限制

这是结构化案例推理，不是已构建的现场知识图谱。合成完井方式表现不能支持真实工程选择，出水编码只参与相似度而非实际水锥模拟。

全部数据均为固定种子20261023的教学合成或显式教学案例表，未采集现场数据，不得宣传为实测收益。交互参数调节后的同一评价集只用于教学探索，不构成新的独立验证。原场景可能列出深度网络、知识图谱或强化学习方向，本例仅实现说明中的轻量方法。
