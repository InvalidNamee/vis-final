# 管柱热压载荷约束比较

## 业务对象

温度变化引起热伸长，封隔器约束又会把伸长转成轴向载荷；压差和自重进一步改变管柱受力。逐工况计算有助于发现高温高压组合下的裕度不足。本例用可解释的简化机理直接计算候选壁厚，展示热载荷、压力活塞力和重量的组成，不以固定安全系数替代计算。

资料查阅：2026-10-23。上述资料仅支持明示的定义与方法动机，不支持本例系数、阈值、型号、准确率或现场收益。

## 实际算法与数据

直井73mm管外径；轴向重量+活塞−全约束热膨胀，薄壁环向应力和简化von Mises。忽略弯曲、摩阻、屈曲、接头、腐蚀、三轴/符号耦合，不构成管柱强度校核。

1. 固定73mm外径，输入长度、温升、压差、壁厚和屈服编码。
2. 计算浮重、活塞力、全约束热力及自由热膨胀。
3. 用薄壁环向与简化轴向组合应力求教学屈服比。
4. 枚举4–10mm壁厚，选满足教学系数的最小质量候选。

默认输入（量纲见标签）：

- 管柱长度 / m：默认 2000，范围 500–3500，步长 100。
- 温升 / °C：默认 40，范围 0–100，步长 5。
- 内外压差 / MPa：默认 15，范围 0–35，步长 1。
- 当前壁厚 / mm：默认 6，范围 4–10，步长 0.25。
- 屈服强度编码 / MPa：默认 550，范围 300–700，步长 25。
- 教学系数下限：默认 1.5，范围 1.1–3，步长 0.1。

## 指标与计算

教学系数=屈服强度/简化组合应力；壁厚候选按质量递增比较。保留轴向拉压符号参与组合应力。不是商业管柱软件或经API认证的设计系数。

所有推荐与指标均来自 demo/model.js 的 run(inputs)，没有硬编码“提升比例”。绘图与CSV均读取同一次run结果。

## 教学假设与限制

全约束热假设与自由伸长是两个极端参考，不同时发生。忽略屈曲、弯曲、连接、腐蚀、摩阻和真实封隔器响应，不能据此判定管柱现场安全。

全部数据均为固定种子20261023的教学合成或显式教学案例表，未采集现场数据，不得宣传为实测收益。交互参数调节后的同一评价集只用于教学探索，不构成新的独立验证。原场景可能列出深度网络、知识图谱或强化学习方向，本例仅实现说明中的轻量方法。
